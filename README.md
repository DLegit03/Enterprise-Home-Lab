# Enterprise-Home-Lab

## Summary

This project demonstrates the deployment, governance, and security auditing of a hybrid home lab environment. The lab integrates Active Directory Domain Services (AD DS) for centralized identity management, an EdgeRouter & Ubiquiti AP for network segmentation and remote access, and a Wazuh SIEM for continuous compliance auditing and telemetry monitoring.
